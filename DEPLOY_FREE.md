# LolTube - Деплой бекенда на бесплатный хостинг

## Можно ли хранить видео на GitHub / GitVerse?

**Нет.** 

- **GitHub Pages / GitVerse Pages** - только статика (HTML/CSS/JS). Там нельзя запустить Node.js сервер и нельзя сохранять загруженные файлы.
- **GitHub репозиторий** - не для хранения видео: лимит 100MB на файл, 1-2GB на репо, и нет API для записи видео от пользователей. Если ты будешь пушить видео в репу - она раздуется и GitHub забанит.
- **Итог:** фронт на GitVerse - ок, но видео хранить надо в другом месте.

## Бесплатные бекенд хостинги и их лимиты для видео

### 1. Render.com (самый простой)
- **Плюсы:** 1 клик деплой из GitHub, бесплатный SSL, автомасштаб
- **Минусы:** 
  - **Ephemeral filesystem** - все файлы в `uploads/` удалятся при рестарте/редеплое! То есть загруженные видео пропадут через время.
  - Лимит 100MB на запрос (видео больше 100MB не загрузится)
  - Засыпает через 15 мин без активности (первый запрос 30с просыпается)
  - 750 часов/мес бесплатно
- **Подходит для:** теста, MVP, если не страшно что видео иногда пропадают

### 2. Fly.io (лучший для видео)
- **Плюсы:**
  - **Можно подключить постоянный диск (volume) 3GB бесплатно** - видео НЕ пропадут!
  - Не засыпает, быстрый
  - Поддержка больших файлов (до 2GB)
- **Минусы:** чуть сложнее деплой (через `flyctl`)
- **Подходит для:** LolTube - РЕКОМЕНДУЮ ЭТОТ

### 3. Railway.app
- Дает $5 кредитов/мес, хватит на маленький сервер
- Тоже ephemeral, но можно подключить volume
- Лимит по трафику

### 4. Другие: Koyeb, Cyclic.sh, Replit
- Все с ephemeral диском, видео будут теряться

## Решение для хранения видео бесплатно и навсегда

Если хочешь чтобы видео не пропадали, надо внешнее хранилище:

**Вариант A - Supabase Storage (рекомендую, 1GB бесплатно)**
- 1GB бесплатно, S3-совместимое
- Надо переписать `server.js` чтобы грузить туда
- Я могу сделать версию `server-supabase.js`

**Вариант B - Cloudinary (25GB бесплатно)**
- 25GB бесплатно, отлично для видео, есть транскодинг
- Тоже надо переписать загрузку

**Вариант C - Оставить локально на Fly.io volume**
- 3GB хватит на ~100 видео по 30MB
- Самый простой, не надо переписывать код

## Как задеплоить на Render (быстро)

1. Залей бекенд на GitHub (папку с `server.js`, `package.json`, `public/`)
2. Иди на https://render.com -> New -> Web Service -> выбери репо
3. Build: `npm install`, Start: `node server.js`
4. Env: `PORT=10000` (Render сам задает, но у нас уже `process.env.PORT || 3000`)
5. Deploy -> получишь URL типа `https://loltube-xxxx.onrender.com`
6. В `public/config.js` на GitVerse пропиши:
```js
window.LOLTUBE_API_BASE = 'https://loltube-xxxx.onrender.com';
```
7. Перезалей фронт на GitVerse

## Как задеплоить на Fly.io (с постоянным диском)

```bash
npm install -g flyctl
flyctl auth login
flyctl launch --name loltube-grapescript --region ams --no-deploy
flyctl volumes create loltube_data --region ams --size 3
# В fly.toml добавь:
# [mounts]
#   source = "loltube_data"
#   destination = "/app/uploads"
flyctl deploy
```

Получишь URL `https://loltube-grapescript.fly.dev`
